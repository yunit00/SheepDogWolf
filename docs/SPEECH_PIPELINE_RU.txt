Русский дубляж — состояние и воспроизведение

Рабочий пакет 02.11.2026: 146 игровых WAV, 145 с русскими репликами/монтажом и один оригинальный невербальный файл. Оригинальные чистые архивы и этот невербальный WAV не добавляются в Git: последний восстанавливается из локальной копии при сборке. Смешанные финальные WAV включают сохранённые оригинальные музыкальные/звуковые фрагменты; приватный репозиторий не передаёт права на исходную игру.

Все 146 финальных WAV прошли независимое автоматическое прослушивание/распознавание Gemini. SHA-256 связывает решение с фактически переданными байтами и текстом. Отчёты в localization/ru/speech/final-review; zz-context-v7.json — повторная проверка двух спорных сцен другой моделью с оригинальным контекстом. Старые final-review-unverified-concurrent не используются при допуске. Это автоматическая проверка, не полное ручное прослушивание кампании.

Монтаж: PCM 24 кГц, моно, 16 бит, длительность исходной сцены сохранена с точностью до двух отсчётов. Реплики не пересекаются по отсчётам. Обрезание слов для подгонки запрещено; ускорение ограничено 1,3x. Нарезка пакетных записей проходит только по тишине, границы соседних файлов не пересекаются. Перед слабым согласным сохраняются 120 мс, после конца 150 мс. Вступительный кредит вставлен на отметке 2 секунды: «Озвучка игры выполнена телеграм-каналом „Точки над ИИ“».

Голоса: Даффи — OpenAI ballad, остальные роли — Gemini; это синтетические персонажные голоса, не точные копии актёров. Тексты/характеристики голосов переданы OpenAI с разрешения пользователя. Оригинальные записи туда не отправлялись. Gemini разрешены исходники и весь процесс дубляжа. Для отделения фона применяется локальный Demucs. Ключи только из окружения.

Незакрытый художественный пункт: явная утиная шепелявость Даффи. Финальный чистый голос последователен, но отдельная проверка трёх сцен не подтвердила шепелявость. Пробы lisp-v5/v7 дают её, однако содержат искажения/повторы и не допускаются в игровой пакет. Проба v6 чистая, но снова без явной шепелявости. Их нельзя автоматически подменять в финальный набор.

Проверенная сборка пакета из Git:
  build-mac/sdw_langexport /path/to/GameData /path/to/new-font-export
  python3 tools/build_russian_pack.py /path/to/new-font-export /path/to/GameData/Languages/01-Russian --font '/System/Library/Fonts/Supplemental/Arial Narrow Bold.ttf' --game-data /path/to/GameData
Полученный пакет побайтово сравнен с установленным; различий нет.

Инструменты обработки:
  review_source_voices.py -> dub_batch.py / openai_dub.py
  review_tts.py -> split_dub_batches.py -> import_direct_voices.py
  review_dub_files.py -> assemble_dub.py -> review_dub_files.py
  review_final_context.py — только для спорных сцен с оригинальным контекстом
  install_dub.py --check-only — полнота, хэши, QA, формат, длительность, пересечения
  install_dub.py — установка только полного прошедшего пакета в новые папки
  python3 -m unittest discover -s tools -p test_dub_editing.py

Выбранные единицы: Gemini batches, затем OpenAI daffy-v1, v2, v3-split и v4-split. Старые тексты исключаются --skip-obsolete, покрытия проверяет сборщик. Рабочие промежуточные WAV остаются локально. Служебные решения и происхождение сохраняются в JSON. Повторные генерации могут отличаться; воспроизводим именно сохранённый финальный аудиопакет.

OpenAI gpt-4o-mini-tts-2025-12-15 запланирован к снятию 06.01.2027 по проверенной документации; готовые WAV от сервиса не зависят. Новая генерация после этой даты может требовать смены модели. Dessa пока не используется: официальная страница на 02.11.2026 помечает скачивание coming soon, публичный API не подтверждён.
